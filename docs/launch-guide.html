LAUNCH DECISIONS

ENGRAM · THE THREE FORKS BEFORE GOOGLE PLAY

01 — HOW TO SHIP TO PLAY STORE

OPTION A · RECOMMENDED

Bubblewrap / TWA

  • What: thin native container rendering your live web app
  • Updates: instant — deploy to your host, no store review for content
  • Size: hundreds of KB
  • Play Store: this is Google's sanctioned PWA path
  • Trade-off: fewer native APIs; no iOS
OPTION B · LATER

Capacitor

  • What: bundled WebView + native bridge & plugins
  • Updates: new store build per release (unless OTA service)
  • Size: a few MB shell
  • Gift: same codebase can produce an iOS App Store build
  • Cost: ~1–2 days of splash/asset/signing ceremony
VERDICT — Ship Play Store with A. Revisit B when iOS or native plugins (billing, notifications) enter the roadmap.

02 — WHERE PROGRESS LIVES

OPTION A

Firebase

  • Model: Firestore NoSQL documents
  • Auth: Google / anonymous included
  • Pricing: generous free tier, scaling cliff
  • Lock-in: proprietary
OPTION B · RECOMMENDED

Supabase

  • Model: Postgres — leaderboards are literally SELECT … ORDER BY score LIMIT 10 per mode
  • Fits the code: SaveBundle + mergeSave map 1:1 onto profiles + scores
  • Portability: open source, self-hostable, plain SQL
  • Effort: ~100 lines against the existing save layer
VERDICT — Supabase, unless the team already lives inside Firebase.

03 — WHO COUNTS THE DUEL SCORE

OPTION A · SHIPPED TODAY

URL-embedded duels

  • Trust: self-reported scores in the link
  • Latency: zero — no server at all
  • Precedent: Wordle ran the same model on the way to millions
OPTION B · WITH BACKEND

Server-validated duels

  • Trust: scores written by the server, leaderboard-grade
  • Requires: Fork 02 completed first
  • Unlocks: global ladders, matchmaking, anti-cheat
VERDICT — Launch with A; adopt B the same week sync ships, not before.

FLIGHT CHECK — BEFORE YOU PRESS PUBLISH

  1. Deploy dist/ to HTTPS and verify /manifest.webmanifest + /sw.js return 200.
  2. Host .well-known/assetlinks.json (Digital Asset Links) and validate it in bubblewrap.
  3. bubblewrap init → build, sign, upload the .aab, and read the pre-launch report on real devices.
  4. One hand, one cheap phone: play a full run with TalkBack on and the brightness to zero weirdness out.
  5. Paste the in-game Privacy URL into Play Console; fill Data Safety as “collects nothing”.
  6. Set a reminder: streak users deserve a win in week one — ship Supabase sync while the first cohort is still warm.
